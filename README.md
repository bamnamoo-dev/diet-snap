## ✨ 핵심 기능 (Features)

1. **⚡ 1.2초 초고속 AI 자동 분석 (Google Gemini 3.5 Flash-Lite)**
   - 사진 1장 촬영 시 수동 입력 없이 **메뉴명, 총 칼로리, 탄단지(탄수화물/단백질/지방), 인스타 감성 한 줄 평**을 1.2초 내 자동 도출합니다.
2. **📱 100dvh 풀스크린 노스크롤 에디터 (No-Scroll Interaction)**
   - 모바일 브라우저 스크롤을 0%로 고정하여 화면 흔들림을 원천 차단했습니다.
   - 캔버스 바로 밑에 6종 템플릿과 퀵 보정 바, 데코 스티커를 밀착 배치하여 손가락 하나로 모든 조작을 끝냅니다.
3. **🔍 음식 사진 실시간 확대 및 자르기 (Zoom & Pan & Crop)**
   - 캔버스 우상단 `[-] 1.0x ~ 3.0x [+]` 미니 툴바 및 핀치 줌 / 마우스 휠 줌을 지원합니다.
   - 상하좌우 자유 드래그로 원하는 음식 구도를 정밀하게 크롭하고, 원클릭 초기화(`↺`)를 지원합니다.
   - 며칠 뒤 갤러리에서 과거 식단을 다시 불러와도 조절해둔 확대/자르기 구도와 스티커가 100% 복원됩니다.
4. **🎨 6대 감성 스탬프 템플릿 (인스타 감성 룩 완성)**
   - **🧾 성수 영수증**: 클래식 화이트 아크릴 영수증과 리얼 바코드 그래픽.
   - **🌸 핑크 라벨**: 힙하고 러블리한 성수동 감성 핑크 라벨 영수증 (PRO).
   - **📷 폴라로이드**: 자동 클리핑(자르기) 화이트 액자와 초볼드 탄단지 카드.
   - **🎫 빈티지 티켓**: 레트로 영화/비행기 보딩패스 티켓 스타일 스탬프 (PRO).
   - **✨ 보그 매거진**: 2030 여성을 사로잡는 하이패션 매거진 표지 룩 (`VOGUE DIET` 대형 세리프 타이포 + 다크 글래스모피즘 매크로 카드, PRO).
   - **📼 Y2K 필름**: 90년대 디지털 캠코더 특유의 힙한 뷰파인더 룩 (`REC ●` & `SP 0:02:45` OSD + 네온 그린 타임스탬프 & 픽셀 매크로, PRO).
5. **🏷️ 원터치 인스타 데코 스티커 6종 (다중 부착 지원)**
   - 사진 위에 입체적인 3D 그림자가 가미된 감성 캡슐 뱃지 형태로 원터치 부착:
   - `오식완 ⭕` (식단 완료), `클린식단 🥗` (다이어트), `치팅데이 🍕` (합법 치팅), `단백질 30g+ 🥩` (고단백), `간헐적단식 ⏳` (공복 성공), `No Sugar 🚫` (무설탕/제로).
6. **🍽️ 끼니 분류(아침·점심·저녁·간식·치팅) 자유로운 수정 & 스마트 시간 자동 감지**
   - 현재 시간대를 감지하여 아침(05~10시), 간식, 점심(11:30~14:30), 저녁(17:30~21:30), 치팅(21:30~05시)이 100% 자동 세팅됩니다.
   - 에디터 메인 화면 2단 바에서 원터치 칩으로 즉시 전환할 수 있으며, 일간/주간 보고서에 자동 반영됩니다.
7. **📐 9:16 (인스타 스토리) 기본 + 1:1 (일반 피드) 원터치 전환**
   - 인스타 스토리에 최적화된 9:16 세로 풀스크린 롱 영수증이 기본으로 렌더링됩니다.
   - 캔버스 좌상단 `[9:16 스토리 ⇄ 1:1 피드]` 버튼 클릭 한 번으로 정사각형 피드/카톡 규격으로 즉시 변환됩니다.
8. **📊 식단 보고서 3종 & 사진첩 일괄 저장 (갤러리 대시보드 집약)**
   - **① 일간 식단 보고서**: 오늘 하루 3끼 사진(1~4분할 콜라주) + 총 칼로리/탄단지 합산 롱 영수증.
   - **② 트레이너 쌤 제출용 식단표 (PRO)**: PT 코치 카톡 전송용 A4 화이트 정밀 매크로 표.
   - **③ 주간 결산 영수증 (PRO)**: 최근 7일간 일평균 칼로리 및 단백질 목표 달성률 롱 영수증.
   - **📸 영수증 사진첩 일괄 저장**: 저장된 식단들을 1080×1920 완성형 영수증으로 스마트폰 사진첩에 원클릭 일괄 저장.
   - **💾 데이터 백업 및 복원**: JSON 파일 원클릭 다운로드 및 기기 간 복원 지원.
9. **👑 합리적인 비즈니스 모델**
   - 무료: 하루 3장 무료 촬영, 우측 하단 워터마크, 기본 일간 모아보기 제공.
   - Pro: **연 5,500원(월 458원 꼴, BEST) 또는 월 990원**, 매일 15장 충전, 워터마크 제거, 6종 템플릿 및 고급 리포트 무제한.

## 🛠️ 기술 스택 & 모듈 아키텍처 (Architecture)

* **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide React
* **Graphic Engine**: 4계층 모듈형 HTML5 Canvas API (`src/canvas/`)
  - `core/`: 줌(1.0~3.0x)/팬/클리핑(`drawImageCover.ts`), 한글 자동 줄바꿈(`wrapText.ts`), 감성 바코드(`drawBarcode.ts`)
  - `stickers/`: 6종 원터치 인스타 데코 스티커 렌더링 엔진 (`drawStickers.ts`)
  - `templates/`: 6종 독립 템플릿 (`receipt`, `pinkReceipt`, `polaroid`, `vintageTicket`, `magazine`, `y2k`)
  - `index.ts`: 템플릿 라우터 및 워터마크 결합 엔진
* **AI Engine**: Google Gemini API (`gemini-3.5-flash-lite`, 단일 JSON 응답 캡슐화, 1.2초)
* **Storage Engine**: IndexedDB (대용량 식단 영구 보관) + LocalStorage (세션 즉시 복원 방어)
* **Infrastructure**: Vercel Edge Serverless Function (`/api/analyze.ts`) + GitHub CI/CD

## 🚀 로컬 실행 방법

```bash
# 1. 저장소 클론
git clone https://github.com/bamnamoo-dev/diet-snap.git
cd diet-snap

# 2. 패키지 설치
npm install

# 3. 환경 변수 설정 (.env.local)
GEMINI_API_KEY=your_gemini_api_key_here

# 4. 개발 서버 실행
npm run dev
```
